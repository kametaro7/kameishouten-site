ソフトウェア

テロップメーカー

動画の話し声を自動で文字起こしし、テロップを入れて書き出す macOS 用のソフトウェアです。文字起こしから書き出しまで、すべてお使いの Mac の中で処理します。動画を外部のサーバーへ送信しません。

無料 macOS 用 登録不要 日本語の音声に対応
テロップメーカーをダウンロード telop-maker-1.0.0.zip / 71KB / 2026年9月23日公開

できること

  • 話し声を自動で文字起こし話している区間を検出し、その区間に合わせてテロップを割り付けます。
  • 画面で直せる文言・表示時間・区切りを、動画を再生しながら調整できます。聞き取りがあいまいな箇所には印が付きます。
  • 見た目を選べるYouTube字幕風・バラエティ風・黒帯など6種類。書体・大きさ・色・フチ・位置も変えられます。
  • 書き出しテロップを焼き込んだ動画（MP4）と、字幕ファイル（SRT）を書き出せます。4K・HDR・縦向きの動画にも対応します。

使いはじめるまで

はじめの 1 と 2 は最初の一度だけです。次からは 4 の起動だけで使えます。

  1. 必要なソフトを入れる

    「ターミナル」を開いて、次の 1 行を貼り付けて実行します（数分かかります）。

    brew install node ffmpeg-full whisper-cpp

    Homebrew を入れていない場合は、先に Homebrew の公式サイトの手順で導入してください。

  2. 音声認識用のデータを入れる

    同じくターミナルで実行します。合計約 1.7GB をダウンロードします。

    mkdir -p ~/whisper-models
curl -L -o ~/whisper-models/ggml-large-v3-turbo.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
curl -L -o ~/whisper-models/ggml-silero-v5.1.2.bin https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin

  3. アプリをダウンロードして置く

    上のボタンから ZIP をダウンロードし、ダブルクリックで展開します。出てきた telop-maker フォルダは、書類フォルダなど好きな場所に置いてください。

    インターネットからダウンロードしたファイルは macOS が実行を止めるため、ターミナルで次を実行して制限を外します（フォルダの場所に合わせて書き換えてください）。

    xattr -dr com.apple.quarantine ~/Downloads/telop-maker

  4. 起動する

    フォルダの中の 起動.command をダブルクリックします。ターミナルが開いたあと、ブラウザにテロップメーカーの画面が表示されます（http://127.0.0.1:8767/）。

    終了するときは、開いているターミナルのウィンドウを閉じてください。

使い方

  1. 動画を入れる

    最初の画面に動画をドラッグ＆ドロップします。読み込みのあと、自動で文字起こしが始まります。10分の動画で1〜2分が目安です。

  2. テロップを直す

    右側の一覧で文言を直します。行をクリックするとその場面に移動し、下の波形では帯の端をドラッグして表示時間を変えられます。聞き取りがあいまいな行には「要確認」の印が付きます。同じ間違いが何度も出るときは「置換」でまとめて直せます。

  3. 見た目を選ぶ

    「デザイン」タブでテロップの種類を選び、書体・大きさ・色・フチ・位置を調整します。「仕上がりを確認」を押すと、書き出したときと同じ見た目を静止画で確認できます。

  4. 書き出す

    「書き出し」タブで、テロップを焼き込んだ動画（MP4）または字幕ファイル（SRT）を書き出します。書き出したファイルはアプリ内の「書き出し」フォルダに保存され、画面のボタンから Finder で開けます。

動画は Mac の外に出ません。文字起こしも書き出しも、すべてお使いの Mac の中で処理します。アプリが通信するのは、準備のときに音声認識用のデータをダウンロードするときだけです。

困ったときは

最初の画面に「必要なものが見つかりません」と出る

「使いはじめるまで」の 1 と 2 が終わっているかご確認ください。画面には足りないものの名前が表示されます。

起動.command をダブルクリックしても開かない

ダウンロードしたファイルに macOS の制限が付いたままの可能性があります。手順 3 の xattr -dr com.apple.quarantine … を実行してください。それでも開かないときは、ファイルを右クリックして「開く」を選んでください。

ほかのアプリで使っていた ffmpeg が動かなくなった

ffmpeg-full を入れると、関連するライブラリが更新されて通常の ffmpeg が起動しなくなることがあります。ターミナルで brew upgrade ffmpeg を実行すると直ります。

聞き取れていない言葉がある

音量が小さい動画や、BGM に重なった小声は取りこぼすことがあります。テロップは手で追加・修正できます。固有名詞など毎回同じ間違いが出る場合は、「置換」で直したうえで辞書に登録すると、次回から自動で直ります。

取り込んだ動画はどこに保存される？

アプリ内の data フォルダに取り込んだ動画の複製が保存されます。動画と同じくらいの空き容量を使うため、不要になったものは一覧の「削除」で消してください。
